# Security reporting

For a suspected security issue, contact the repository owner privately or use
GitHub's private vulnerability reporting when enabled. Do not put credentials,
customer scenes, or confidential file paths in public issues.

The runtime does not require an MCP port, network server, API key, or cloud service.
The recovery worker runs the Maya executable installed beside the current host
and imports only the Maya ASCII file generated by that local worker. It does
not download or execute a remote Maya script.

Use ordinary care with untrusted USD packages and host plugins. Package hashes
check consistency; they are not authenticated signatures or a trust boundary.
