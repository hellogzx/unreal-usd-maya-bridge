# 使用指南

## 最简导入

1. 选择 `.usd`、`.usda` 或 `.usdc` 根层。
2. “转换为”选择 Standard Surface，或 Phong（预览近似）。
3. 点击导入。工具会添加原生网格、受支持的摄影机和新材质。

每次导入都是新增，不会替换之前导入的那份模型，也不会自动保存场景。
一个完整导入可以通过一次撤销移除，并支持重做。

“PBR 示例”只选好仓库中的合成样例，随后仍需点击导入。
“选择模型”“选择材质”针对最近一次成功导入；底部详情显示实际图片与警告。

## 四个手动贴图栏

留空使用 USD 原材质的图片或常量。灰色提示文字不是手动路径。
选择一张 PNG/JPEG 可以替换对应通道，清空该路径恢复使用 USD 原值。

多材质文件才显示材质选择框。手动替换只作用于选中的 USD 材质，其他材质保留。
没有材质但带 st UV 的模型也可以手动连接四图；缺 UV 时停止，不自动展开 UV。

Metallic 和 Roughness 手动输入应为独立灰度图，工具按 R 读取。
若原 USD 已记录 ORM 的 G/B 连接，留空让工具自动拆分即可。
ORM 不能恢复 Normal，法线必须另有 RGB 图片。

## 更多选项

- **Normal 翻转绿色通道**：源为 DirectX 法线且需要翻转时开启。默认按 OpenGL
  切线空间读取；不是高度图或位移图。
- **独立图片输出目录**：留空时写到源 USD 同级 `Maya_PBR_Textures`，也可填写
  可写目录。生成图片有内容哈希校验，重复导入会核验复用，损坏时重建。

原图和源 USD 不覆盖。撤销删除节点而不删除缓存图片，因为重做和保存后的场景
仍依赖这些文件。原 USD 有缺图时，可以手动替换缺失通道；仍被使用的缺图会阻止导入。

## 完整面板

保留旧的基础 Phong、Standard Surface、USD Stage、检查、报告及相机功能。
旧 Phong 路线的支持范围比简易窗口新增的四通道 Phong 更小，两者内部模式不同。

USD Stage 模式保留代理引用，模型不会变成可直接编辑的 Maya mesh。
相机“匹配源画幅”是显式操作，会更改全局输出尺寸并可以撤销；导入本身不自动
改变渲染尺寸或当前渲染摄影机选择。

## 当前边界

支持静态 Mesh、支持的透视摄影机、厘米、Y-up、UsdPreviewSurface 金属／粗糙度、
直接 UsdUVTexture、st UV 与 repeat。拒绝未支持的材质网络，避免静默丢通道。

暂不转换动画、骨骼、曲线、程序化几何、UDIM、贴图序列、UV 变换、多 UV 集、
MaterialX、Gazebo、透明、位移、AO 合成或自发光。最终外观还取决于灯光、环境和
色彩管理。Phong 尤其应作为预览使用。
