# 验证范围

## 本次仓库整理

v0.9.2 基于已在实际工作会话修复空网格导入的 v0.9.1 整理。
主要改变是统一格式、独立项目结构、可移植测试／打包、文档与合成示例入口。
运行时不要求连接 ChatGPT 或 MCP。

测试结果以实际生成的报告和 GitHub Actions 状态为准。CI 仅运行纯 Python
检查和打包，不拥有 Maya 或 Unreal，因此不会声称在云端执行过 DCC 验收。

2026-11-21，本次整理目录已经重新通过：15 个纯 Python 单元测试、Black 格式与
仓库可分享检查；独立 Maya 2023 的完整 PBR／缓存／位深／绑定测试，以及简易 UI、
四通道手动替换、Phong 数值、缺图修复、相机、兼容子进程、撤销重做和保存重开。
新的测试仅依赖本仓库合成资源，不需要下载模型或历史本机报告。

## 已有真实会话证据

v0.9.1 曾在原先报错的 Windows Maya 2023 会话验证：

- 正常检查能读到 Mesh，而原生导入只创建空层级；简单网格与茶碗同样受影响。
- 兼容读取后，Standard Surface 和 Phong 均导入古董相机的两个网格、两个材质、
  八个独立 file 节点。
- 测试高度约 160cm，四通道存在，撤销／重做通过，原有节点保留。

这些是已有版本的真实会话记录，不替代 v0.9.2 的重新验收。
测试当时未证明异常状态的最初触发原因，未作与 Unreal 的最终渲染等价比较。

## 仓库可复现的验收层级

| 检查 | 如何运行 | 能证明什么 |
| --- | --- | --- |
| 单元测试 | `python -m unittest discover -s tests/unit` | 数学、策略、清单与路径边界 |
| 格式／仓库检查 | Black 与 `scripts/check_repository.py` | 格式、语法、链接、可分享目录 |
| Maya 集成 | `scripts/run_maya_tests.py --mayapy ...` | 实际材质、几何、UI、回滚、Undo、独立读取 |
| 发布哈希 | `scripts/build_release.py --validation-dir ...` | 报告针对当前运行模块 |
| 解压运行 | 对最终 ZIP 的独立安装目录运行工作流测试 | 发布附件依赖闭合 |

生成的完整日志、临时 Maya 文件和本机路径保留在忽略目录。
发布 ZIP 仅包含过滤后的宿主环境、验收标志和相对文件哈希。

## 已知限制

只验收 Windows / Maya 2023 / Maya USD 0.16.0；不将其他宿主版本或 Linux CI
标记为 Maya 支持。Unreal 导出器继承本机 UE 5.8.4 的 v0.5.0 验收，本次仅整理
格式和项目结构，未新增 UE 导出功能。

Phong 是预览近似。兼容读取会增加启动时间，可能展开实例。像素提取校验与
节点连接校验不保证任意生产材质、灯光、环境、色彩管理下的外观等价。
