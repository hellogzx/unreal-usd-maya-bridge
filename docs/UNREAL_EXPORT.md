# Unreal 导出到 USD

## 准备

现有导出器已在本机 Unreal Engine 5.8.4 验收，版本仍为 v0.5.0。
仓库整理未新增导出功能，也未把其他 UE 版本标记为已验证。

在编辑器中启用 Python Editor Script Plugin 和 USD Importer，按 UE 要求重启。
通过 **Tools → Execute Python Script** 执行仓库根目录的 `launch_unreal_usd.py`。

## 导出步骤

1. 选择“选中对象”或“已加载对象”范围。
2. 检查可导出组件、实例、摄影机及跳过原因。
3. 选择输出目录、LOD 策略和 USDA/USDC 资源格式。
4. 导出一个新包，在 Maya 选择包内的 `scene.usda`。

默认不会主动加载 World Partition 区块、流送关卡或数据层。要交接的内容应先
在编辑器中加载。检查不会运行 Construction Script 或自动保存工程。

## 保留与限制

保留受支持的静态网格摆放、世界变换、比例、组件／实例来源和静态透视摄影机。
输出统一厘米、Y-up，并写来源清单、几何选择和文件哈希。

检查与交接不自动导出任意 UE 材质网络，也不烘焙 PBR 贴图。若 USD 中没有材质，
Maya 可以分配默认材质；这不意味着 UE 的外观已迁移。

Nanite 默认保守处理；显式允许时只读取现有渲染／回退代理，标明近似来源。
指定 LOD 不存在时按选择的策略跳过或回退，不改变源组件设置。

不支持完整 Nanite 源网格恢复、动画、骨骼、植被系统、SplineMesh、Landscape、
灯光交接或整套影视渲染场景迁移。跳过项应在交付前逐条检查。

来源清单完整性校验可发现文件缺失或内容变更，但不是数字签名或来源认证。
本机 Maya USD 目标对 USDC Crate 版本有限制，超出已支持版本的包会被拒绝。
